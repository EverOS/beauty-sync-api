# Beauty Sync API

API RESTful para gestão de agendamentos em salões de beleza.

## 🛠 Tecnologias
- Node.js (v24+)
- Docker (Containerização)

## 🎯 Objetivo
Desenvolver uma plataforma robusta de agendamentos, aplicando práticas de Clean Architecture, CI/CD e infraestrutura como código (IaC).
